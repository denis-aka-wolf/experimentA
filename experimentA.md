# Описание выявленных закономерностей

Экспериментом выявили закономерность, которую стоит исследовать отдельно.

Добавление характеров действительно увеличило число уникальных отпечатков с 2 до 37. Но ни один из использованных наборов не смог различить точки \\(P\\) и \\(-P\\).

Причём это не случайная коллизия и не недостаточная точность вычислений. Здесь проявилась структурная симметрия.

## 1. Результаты эксперимента

| Набор характеров  | Уникальных отпечатков | Коллизийных групп |
| ----------------- | --------------------- | ----------------- |
| \\(S_2\\)         | 2                     | 1                 |
| \\(S_2+S_3\\)     | 34                    | 33                |
| \\(S_2+S_3+S_6\\) | 37                    | 36                |
| Все характеры     | 37                    | 36                |

Количество различных отпечатков среди 73 точек подгруппы.

010203040S₂S₂ + S₃S₂ + S₃ + S₆Все

Что это означает:

- \\(S_2\\) практически не содержит информации о конкретной точке.
- \\(S_3\\) добавляет существенную информацию.
- \\(S_6\\) устраняет ещё три класса коллизий.
- Аддитивные характеры в данном эксперименте не устраняют оставшиеся коллизии.

Последний пункт особенно важен: увеличение числа характеров не обязательно увеличивает различающую способность.

## 2. Самое важное открытие: симметрия

Результат:

72 из 72 совпадений

Для каждой ненулевой точки:

\\[ P=(x,y) \\]

существует противоположная точка:

\\[ -P=(x,p-y). \\]

А характерные суммы используют только \\(x\\)-координату:

\\[ \chi(x-x_P),\qquad \chi_2(f(x)). \\]

Поэтому:

\\[ \boxed{F(P)=F(-P)} \\]

Это математически неизбежно. Ни увеличение числа характеров, ни добавление новых частот в аддитивном характере не поможет, пока мы используем только \\(x_P\\).

Но есть ещё одна интересная деталь.

## 3. Что удалось получить на самом деле

Результаты `ALL`:

37 уникальных отпечатков для 73 точек.

Из них:

- одна точка является бесконечно удалённой точкой \\(O\\);
- остальные 72 точки образуют 36 пар \\(P,-P\\).

Получается, что в этом эксперименте полный набор характеров различает все 36 различных значений \\(x\\) в нашей подгруппе.

То есть мы получили:

\\[ \boxed{\text{Отпечаток}\longrightarrow x(P)} \\]

с точностью до симметрии \\(P\leftrightarrow -P\\).

Это хороший результат для маленькой кривой.

Но есть важное ограничение: он получен на подгруппе всего из 73 точек. Сохранится ли такая различимость на больших кривых?

## 4. Обнаружилась ещё одна особенность S2

В коде:

```
S2 += chi2
```

Здесь вообще нет зависимости от \\(x_0\\).

Поэтому для всех конечных точек \\(S_2=11\\).

Второе значение отпечатка, ноль, появляется исключительно из-за того, что для бесконечно удалённой точки мы вручную возвращаем нулевые суммы.

Следовательно, \\(S_2\\) нужно исключить из дальнейшего поиска различимости точек.

Это полезная поправка к эксперименту.

## 5. Следующий эксперимент: добавить информацию о y

Теперь необходимо изменить саму конструкцию.

Вместо суммирования только по координате \\(x\\) будем использовать все аффинные точки кривой:

\\[ R=(u,v)\in E(\mathbb F_p). \\]

Определим новую сумму:

\\[ T_t(P)= \sum\_{R\in E(\mathbb F_p)} \chi_3(u-x_P) \psi(t(v-y_P)), \\]

где:

\\[ \psi(z)=e^{2\pi iz/p}. \\]

Теперь в формуле присутствуют обе координаты исследуемой точки.

Для противоположной точки:

\\[ T_t(-P)= \sum\_{R\in E(\mathbb F_p)} \chi_3(u-x_P) \psi(t(v+y_P)). \\]

Здесь уже нет обязательного равенства:

\\[ T_t(P)=T_t(-P). \\]

Именно это нам нужно проверить.

3. Какие значения \\(t\\) дают наибольшую различающую способность?
4. Можно ли объединить старые и новые характеры, чтобы получить уникальный отпечаток каждой точки?
