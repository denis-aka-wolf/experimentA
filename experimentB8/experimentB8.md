Здесь мы исправим важную методологическую проблему и проверим более сильное утверждение: можно ли восстановить саму точку эллиптической кривой по одному комплексному отпечатку, используя точное комплексное условие, а не только округление фазы?

Сначала важная поправка к моему предыдущему выводу. В B7 мы округляли фазу отношения \(T/A\) до ближайшего целого, но не проверяли, насколько само отношение близко к соответствующему корню из единицы. Поэтому дополнительные кандидаты могли быть ложными. Пересечение двух списков кандидатов B7 само по себе не доказывает однозначного восстановления. Это моя ошибка в интерпретации результатов.

В B8 исправляем это.
Что будет проверять B8
Используем равенство:
\[
\frac{T_t(x,y)}{A_t(x)}
=
e^{-2\pi ity/499}.
\]

Для каждого предполагаемого \(x'\):
1. Вычисляем \(T_t/A_t(x')\).
2. Находим ближайший корень 499-й степени из единицы.
3. По нему получаем предполагаемый \(y'\).
4. Проверяем, лежит ли \((x',y')\) на кривой.
5. Проверяем комплексную ошибку:
\[
\boxed{
\varepsilon=
\left|
\frac{T_t}{A_t(x')}
-
e^{-2\pi ity'/499}
\right|
}
\]

Это принципиально важный шаг, которого не хватало B7.

Я предварительно проверил эту методику на всей кривой. Для частот 1 и 174 максимальная ошибка правильного кандидата составляет приблизительно \(10^{-13}\), а минимальная ошибка ложного кандидата составляет соответственно около 0,00420 и 0,00474. При допуске \(10^{-3}\) обе частоты дают однозначное восстановление всех 510 аффинных точек в численном эксперименте.

4. Следующий эксперимент B9: спектральная структура скаляра
Предлагаю сменить направление исследования.

До этого мы пытались обнаружить зависимость между \(T(kG)\) и \(k\) через обычную геометрию, расстояния, линейные модели и фазы.

Теперь исследуем другую возможность.

Представим последовательность:
\[
Z_k=T_t(kG),\qquad k=1,\ldots,72.
\]

Вычислим её дискретное преобразование Фурье:
\[
\widehat Z_m=
\sum_{k=0}^{72}
Z_k e^{-2\pi i mk/73}.
\]

Нас интересует, распределена ли энергия по всем 73 частотам или сосредоточена в небольшом количестве компонент.

Если обнаружится выраженная спектральная концентрация, проверим возможность приближённого представления:
\[
Z_k\approx
\sum_{m\in M}
c_m e^{2\pi i mk/73},
\]

где \(M\) содержит лишь небольшое количество частот.

Это будет совершенно новый подход.

B9 должен ответить на четыре вопроса:
1. Есть ли у последовательности отпечатков выраженные спектральные пики?
2. Сколько гармоник необходимо для восстановления последовательности с заданной точностью?
3. Можно ли предсказывать отпечаток для неизвестного \(k\), используя только часть известных значений?
4. Можно ли по спектральной структуре определить \(k\), не перебирая все 73 значения?
Последний пункт самый важный. Мы не будем считать успехом простое восстановление последовательности по уже известным скалярам.

Моя рекомендация: перейти к B9 и исследовать спектральную структуру сразу для \(t=1\) и \(t=174\), отдельно для действительной, мнимой и комплексной частей.
