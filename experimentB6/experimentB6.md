Это не случайное совпадение численных значений.

В поле \(\mathbb F_{499}\) существуют два нетривиальных кубических корня единицы:
\[
\omega=139,\qquad \omega^2=359.
\]

Они удовлетворяют:
\[
\omega^3\equiv1\pmod{499},
\]

\[
\omega\ne1,\qquad \omega^2\ne1.
\]

Посмотрим на первую группу:
\[
3\cdot139\bmod499=417,
\]

\[
3\cdot359\bmod499=79.
\]

Получаем ровно три координаты из таблицы:
\[
\boxed{\{3,417,79\}}.
\]

То же преобразование объясняет все остальные группы.
Структурная закономерность
Почему это происходит?

Наша кривая имеет уравнение:
\[
y^2=x^3+7.
\]

Если умножить \(x\) на \(\omega\), то:
\[
(\omega x)^3=\omega^3x^3=x^3.
\]

Следовательно:
\[
y^2=(\omega x)^3+7=x^3+7.
\]

То есть преобразование
\[
(x,y)\longrightarrow(\omega x,y)
\]

сохраняет принадлежность точки кривой.

Это не просто симметрия самой кривой. Она проявляется и в наших отпечатках.

В сумме, определяющей \(A_t(x)\), можно заменить переменную \(u\) на \(\omega u\). Преобразование сохраняет кривую, а кубический характер при умножении аргумента на \(\omega\) приобретает постоянный множитель:
\[
\chi_3(\omega)=e^{2\pi i/3}.
\]

Поэтому:
\[
A_t(\omega x)=\chi_3(\omega)A_t(x).
\]

И, следовательно:
\[
\boxed{|A_t(\omega x)|=|A_t(x)|}.
\]

Поскольку:
\[
|T_t(P)|=|A_t(x_P)|,
\]

получаем:
\[
\boxed{
|T_t(x,y)|
=
|T_t(139x,y)|
=
|T_t(359x,y)|
}.
\]

Вот почему 36 координат распались ровно на 12 групп по три. И вот почему эта структура сохранилась для обеих частот.

Это уже не случайная численная закономерность, а следствие симметрии кривой и выбранного характера.
3. Модуль не позволяет определить x однозначно
Теперь становится понятно, почему программа обнаружила только 12 различных модулей для 36 координат.

Модуль отпечатка сохраняет информацию о классе:
\[
x,\quad139x,\quad359x\pmod{499},
\]

но теряет информацию о том, какая именно из трёх координат была исходной.

Таким образом:
- по модулю можно определить одну из 12 групп;
- внутри группы остаются три возможных значения \(x\);
- для выбора конкретного значения нужна дополнительная информация.
Это важный ориентир для следующего эксперимента: надо исследовать, что именно сообщает комплексная фаза и можно ли совместить её с модулем так, чтобы восстановить координату однозначно.

7. Что я предлагаю сделать в B7
Теперь у нас появилась конкретная математическая структура, которую можно исследовать.

Я предлагаю не перебирать новые частоты, а проверить, можно ли восстановить координату \(x\) из комплексного отпечатка с учётом обнаруженной тройной симметрии.

Для этого нужно исследовать три направления:

Первое. Фаза отпечатка.

У нас есть:
\[
T_t(P)=A_t(x)e^{-2\pi ity/499}.
\]

При умножении \(x\) на кубический корень единицы меняется фаза \(A_t(x)\), но не модуль. Проверим, можно ли по фазе определить, какой из трёх представителей группы соответствует исходной точке.

Второе. Точные отношения внутри тройки.

Проверим:
\[
\frac{A_t(139x)}{A_t(x)}
\]

и
\[
\frac{A_t(359x)}{A_t(x)}.
\]

Наша гипотеза:
\[
\frac{A_t(139x)}{A_t(x)}
=
e^{2\pi i/3},
\]

\[
\frac{A_t(359x)}{A_t(x)}
=
e^{4\pi i/3}.
\]

Если это подтвердится, тройная симметрия будет описана не только через модули, но и через точное преобразование комплексных значений.

Третье. Восстановление координат из одного отпечатка.

Проверим, можно ли использовать известные таблицы \(A_t(x)\), фазу и модуль для восстановления \(x\) и \(y\), имея только один комплексный отпечаток.

Здесь особенно важно разделить два режима:
- восстановление по заранее рассчитанной таблице всех 36 координат;
- получение координат без полного перебора возможных \(x\).
Первый режим может подтвердить возможность инверсии отпечатка, второй уже интересен с точки зрения поиска более эффективного алгоритма.
