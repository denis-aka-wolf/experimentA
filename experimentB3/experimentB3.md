# Эксперимент B3

В B3 проверим следующий этап без предположений о сопряжённости частот \(t\) и \(499-t\).

Главные задачи эксперимента:
1. Проверить все 498 ненулевых частот: \(t=1,\ldots,498\).
2. Для каждой частоты посчитать количество уникальных отпечатков на всех 73 точках подгруппы.
3. Измерить минимальное расстояние между отпечатками. Это покажет, насколько далеко они находятся друг от друга и не держится ли уникальность на случайном округлении.
4. Проверить внутренние суммы \(A_t(x)\): найти нулевые и близкие к нулю значения.
5. Отдельно проверить все 36 пар противоположных точек \(P\) и \(-P\).

Формулы оставляем прежними:
\[
A_t(x)=\sum_{R=(u,v)\in E(\mathbb F_{499})}
\chi_3(u-x)e^{2\pi itv/499}
\]

\[
T_t(P)=A_t(x_P)e^{-2\pi ity_P/499}.
\]

Суммирование ведётся по 510 аффинным точкам кривой. Точка на бесконечности учитывается отдельно как специальный отпечаток. Внутренняя сумма вычисляется через группировку точек по \(u\), что заметно сокращает количество операций.

## Как запустить

Нужна библиотека NumPy. Если она ещё не установлена:

pip install numpy

Запустить:
python experimentB3.py


Скрипт создаст папку experimentB3 и архив experimentB3.zip.

## Результат B3

Результат B3 получился очень интересным. И главное, он укрепляет результат B2 не просто дополнительным количеством проверок, а проверкой устойчивости и поведения всей системы частот.

На игрушечной кривой все 498 ненулевых частот дали ноль коллизий при точности 10 знаков. Это уже существенно более сильный результат, чем прежняя проверка только для \(t=1\).

Все 498 частот проверены независимо. Никакого предположения о сопряжённости \(t\) и \(499-t\) не использовалось.

Уточнение: 73 отпечатка включают 72 конечные точки и отдельно обозначенную точку на бесконечности. Численные расстояния между комплексными значениями рассчитываются только для 72 конечных точек.

2. Частота t=174 оказалась заметно лучше t=1
Это самое интересное открытие эксперимента.
Показатель	t=1	t=174
Уникальных отпечатков	73	73
Коллизий	0	0
Минимальное расстояние	0,1318	2,4523
Минимальное расстояние P и −P	0,1318	5,0075
Минимум \(|A_t(x)|\)	4,6225	5,0425

Минимальное расстояние между отпечатками при \(t=174\) примерно в 18,61 раза больше, чем при \(t=1\).

Это означает, что частота \(174\) создаёт гораздо более отчётливо разделённое множество комплексных значений.

Но есть тонкость: увеличение расстояния между отпечатками само по себе ещё не означает, что вычисление скаляра \(k\) стало проще.

3. Что говорят расстояния между противоположными точками
Для противоположных точек:
\[
P=(x,y), \qquad -P=(x,-y)
\]

имеем:
\[
T_t(P)=A_t(x)e^{-2\pi ity/p}
\]

\[
T_t(-P)=A_t(x)e^{2\pi ity/p}.
\]

Следовательно:
\[
\boxed{
|T_t(P)-T_t(-P)|
=
2|A_t(x)|
\left|\sin\left(\frac{2\pi ty}{p}\right)\right|
}
\]

И здесь возникает важное свойство.

Для нашей подгруппы порядок равен 73, а модуль поля равен 499. Для всех ненулевых точек подгруппы \(y\ne0\). Поэтому при ненулевом \(t\) аргумент синуса не может быть целым кратным \(\pi\).

Значит, если \(A_t(x)\ne0\), противоположные точки обязательно различаются.

В B3 мы получили:
\[
\min_x |A_1(x)|=4.62249
\]

и
\[
\min_x |A_{174}(x)|=5.04249.
\]

То есть ни одна из 36 проверенных внутренних сумм для этих частот не обнулилась.

Это объясняет, почему противоположные точки так хорошо разделяются.
4. Что мы пока действительно доказали
На конкретной кривой
\[
y^2=x^3+7\pmod{499}
\]

для подгруппы порядка 73 мы получили следующее:
- Все 498 ненулевых частот дают уникальные отпечатки при округлении до 10 знаков.
- Для \(t=1\) уникальность сохраняется даже при округлении до 14 знаков.
- Для \(t=174\) минимальное расстояние между конечными отпечатками составляет примерно 2,4523.
- Ни одна из 36 противоположных пар не совпадает.
- Для всех проверенных частот нет коллизий при выбранной точности.
Это сильное экспериментальное свидетельство инъективности отображения на нашей подгруппе.

Но пока это не доказательство инъективности на произвольных эллиптических кривых. И тем более ещё не алгоритм решения ECDLP.

5. Следующий эксперимент: B4

Теперь можно перейти от вопроса «различаются ли точки?» к гораздо более интересному:

Существует ли закономерность, позволяющая восстановить скаляр \(k\) по комплексному отпечатку?

Для этого B4 должен исследовать структуру отпечатков относительно самого скаляра.

Необходимо проверить четыре направления:
1. Геометрическая последовательность. Рассмотреть комплексные отпечатки \(T_{174}(kG)\) в порядке \(k=0,\ldots,72\). Исследовать, есть ли закономерность в перемещении по комплексной плоскости.
2. Расстояния между соседями. Посчитать расстояния между \(T_{174}(kG)\) и \(T_{174}((k+1)G)\), а также между точками с разностью скаляров 2, 3, 4 и так далее.
3. Корреляция с k. Проверить, можно ли по координатам комплексного отпечатка приблизительно оценить \(k\), используя углы, модули, проекции и другие характеристики.
4. Обратное восстановление. Построить экспериментальную модель, которая получает комплексный отпечаток и пытается определить соответствующий скаляр без перебора всех 73 вариантов.
Последний пункт особенно важен. Он позволит проверить, есть ли у нашего инварианта не только способность различать точки, но и полезная обратная структура.

Вывод: B3 успешно подтвердил, что найденная конструкция обладает устойчивой различающей способностью на нашей игрушечной подгруппе. Теперь пора исследовать, скрывает ли эта конструкция информацию о самом \(k\), а не только о точке \(P\).
