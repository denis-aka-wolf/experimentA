ЭКСПЕРИМЕНТ C2: УСТОЙЧИВОСТЬ ГЕОМЕТРИЧЕСКИХ ПРИЗНАКОВ
==============================================================

Кривая: y^2 = x^3 + 7 (mod 499)
Поле: p=499
Генератор: {'x': 3, 'y': 212}
Порядок генератора: 73
Ненулевых точек подгруппы в выборке: 72
Ориентир случайной точности: 0.013699

Файлы:
- C2_summary.csv: сводные метрики по сериям.
- C2_predictions.csv: фактические и предсказанные скаляры по точкам.
- C2_results.json: полные результаты и параметры запуска.

Метод: leave-one-out Ridge для круговой цели (cos(theta), sin(theta)).
Контроль: случайная перестановка меток скаляров.

ОГРАНИЧЕНИЯ
Этот эксперимент не решает задачу дискретного логарифмирования.
Он исследует только указанные признаки, модель и игрушечную кривую.
Случайные подъёмы координат меняют вещественное представление, но не остатки координат по модулю p.
Поэтому падение качества при подъёмах указывает на зависимость признака от произвольного выбора представителя.
