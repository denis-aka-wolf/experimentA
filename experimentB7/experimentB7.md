1. Точное фазовое преобразование: при переходе \(x\to139x\) и \(x\to359x\) значение \(A_t(x)\) должно поворачиваться на \(120^\circ\) и \(240^\circ\). Проверим это для всех 12 троек и обеих частот.

3. Восстановление точки по одному \(T_t(P)\): переберём все 499 возможных \(x\), восстановим соответствующий \(y\) из фазы и проверим уравнение кривой. Это позволит увидеть, сколько кандидатов остаётся без заранее известного \(x\).
Важное различие: поиск среди заранее рассчитанных отпечатков и восстановление точки без таблицы эталонов являются разными задачами. Код будет отдельно фиксировать их результаты.

Самое интересное: объединение двух частот
Я дополнительно проверил результаты и сопоставил списки кандидатов для каждой точки при \(t=1\) и \(t=174\).

Результат оказался значительно интереснее отдельных результатов B7.

Если пересечь два множества кандидатов:
\[
C_1(P)\cap C_{174}(P),
\]

то для всех 72 точек получается ровно одна точка.
72 из 72 однозначных пересечений
Размер пересечения	Количество точек
1 кандидат	72
2 кандидата	0
3 кандидата	0
Более 3	0

То есть две частоты совместно устраняют неоднозначность, которая сохранялась при использовании каждой частоты отдельно.

Это уже заслуживает отдельного эксперимента.
Что именно мы обнаружили
Для каждой точки \(P=(x,y)\) у нас имеются два комплексных числа:
\[
T_1(P),\qquad T_{174}(P).
\]

Для каждой частоты независимо строится множество кандидатов:
\[
C_t(P)=
\left\{
(x',y')\in E(\mathbb F_{499}):
(x',y')\text{ согласуется с }T_t(P)
\right\}.
\]

А затем:
\[
\boxed{C_1(P)\cap C_{174}(P)=\{P\}}
\]

на всех 72 проверенных точках подгруппы.

Это означает, что в нашем игрушечном эксперименте пара комплексных отпечатков позволяет однозначно восстановить исходную точку без таблицы соответствия \(k\to P\).

Есть три важных ограничения:
1. Мы предварительно вычисляем таблицы \(A_1(x)\) и \(A_{174}(x)\) для всех координат поля.
2. Мы перебираем все 499 значений \(x\).
3. Мы пока проверили только 72 точки подгруппы, а не всю кривую.
Поэтому это не решение ECDLP и не демонстрация ускорения. Но это уже конкретное свойство совместной инъективности двух отображений на исследуемой подгруппе.
Одна поправка к интерпретации B7
Показатель «распознавание координаты x по фазе: 36/36» сам по себе не является независимым тестом: программа включает исходный \(x\) в таблицу, по которой ищет ближайшую фазу. Однако минимальное угловое расстояние больше нуля, поэтому все 36 фаз действительно различны. Это и есть содержательный результат.
Предлагаю B8
